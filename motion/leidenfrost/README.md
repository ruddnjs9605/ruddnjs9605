# 라이덴프로스트 효과 — 코드로 만든 모션 그래픽 (릴스용)

`../rupert-drop`, `../supercooled-water` 와 같은 방식(SVG 장면 + 합성 효과음 + FFmpeg)으로 만든 32.5초 세로 영상(1080×1920, 30fps)입니다.

- 완성본: `leidenfrost_reels.mp4` (효과음 포함, 내레이션 없음)
- 커버: `cover.png` (릴스 업로드 때 "커버 편집 → 카메라 롤에서 추가"로 사용)

## 이전 영상과 달라진 점

- **안전 영역 배치**: 제목은 y 380 아래, 자막은 y 1450 중심. 프로필 그리드(3:4로 잘림, y 240–1680)와 릴스 하단 UI(대략 y 1560 아래)에 가리지 않음
- **워터마크**: `Pagebook`
- **마지막 2.5초**: 다음 편 예고(딱총새우) + 팔로우 유도
- **커버 이미지**: `node render.js cover` 로 따로 생성

## 다시 만들기

필요한 것: Node.js, `playwright`(Chromium 포함), FFmpeg, Python 3 + numpy

```bash
python3 audio.py audio.wav
node render.js video.mp4                 # 975프레임, 수 분 걸림
node render.js cover                     # cover.png
ffmpeg -y -i video.mp4 -i audio.wav -c:v copy -c:a aac -b:a 192k -shortest -movflags +faststart leidenfrost_reels.mp4

# 장면 확인용 정지 화면만 뽑기 (still_<프레임>.png)
node render.js - 40,380,560,880
```

## 장면 구성

| 시간 | 장면 |
|---|---|
| 0–7초 | 150℃ 팬: 치익, 약 1초 만에 증발 / 250℃ 팬: 구슬처럼 굴러다니며 버팀 |
| 7–10.3초 | 제목: 라이덴프로스트 효과 (1756년 기록) |
| 10.3–16초 | 단면: 아랫면이 증발해 수증기 쿠션, 수증기가 열을 막음 |
| 16–22초 | 판 온도별 물방울 수명 그래프, 약 200℃에서 급증 |
| 22–27초 | 스테인리스 팬 예열 확인법 (빈 팬에서만) |
| 27–30초 | 정리: 뜨거울수록 오히려 닿지 않는다 |
| 30–32.5초 | 다음 편 예고 + 팔로우 |

장면 시각은 `index.html` 의 `SCENES` 와 `audio.py` 의 이벤트 시각이 서로 맞춰져 있으니, 한쪽을 바꾸면 다른 쪽도 같이 바꾸세요.

## 수치 근거 (게시 전 확인 권장)

- 라이덴프로스트 점: 물은 금속판 위에서 대략 200℃ 전후 (표면 재질·상태에 따라 달라짐)
- 150℃ 약 1초 / 200℃ 이상 1분 넘게: 작은 물방울로 한 고전 실험의 대표값. 그래프는 정성적 모양이며 정확한 수치 축이 아님
- 수증기 층 두께 약 0.1mm (수십~백 마이크로미터 수준)
- 1756년 요한 고틀로프 라이덴프로스트(독일 의사)가 기록
