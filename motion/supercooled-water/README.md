# 과냉각 물 — 코드로 만든 모션 그래픽 (릴스용)

`../rupert-drop` 과 같은 방식(SVG 장면 + 합성 효과음 + FFmpeg)으로 만든 29.5초 세로 영상(1080×1920, 30fps)입니다.

- 완성본: `supercooled_water_reels.mp4` (효과음 포함, 내레이션 없음)

## 다시 만들기

필요한 것: Node.js, `playwright`(Chromium 포함), FFmpeg, Python 3 + numpy

```bash
python3 audio.py audio.wav
node render.js video.mp4                 # 885프레임, 수 분 걸림
ffmpeg -y -i video.mp4 -i audio.wav -c:v copy -c:a aac -b:a 192k -shortest -movflags +faststart supercooled_water_reels.mp4

# 장면 확인용 정지 화면만 뽑기 (still_<프레임>.png)
node render.js - 60,200,530,700
```

## 장면 구성

| 시간 | 장면 |
|---|---|
| 0–7.5초 | 영하 8℃인데 액체인 물 → 톡 치면 얼음이 퍼짐, 온도는 -8℃ → 0℃ |
| 7.5–10.8초 | 제목: 과냉각 |
| 10.8–16초 | 분자 확대: 얼음 씨앗이 생기려다 흩어짐 |
| 16–21.6초 | 충격 → 육각형 얼음 결정이 퍼짐, 잠열로 0℃ 복귀, 약 10%만 얼어 슬러시 |
| 21.6–26초 | 똑딱이 손난로: 딸깍 → 결정화 → 약 54℃ |
| 26–29.5초 | 끓는 물에 데우면 다시 액체로 → 재사용 |

장면 시각은 `index.html` 의 `SCENES` 와 `audio.py` 의 이벤트 시각이 서로 맞춰져 있으니, 한쪽을 바꾸면 다른 쪽도 같이 바꾸세요.

## 수치 근거 (게시 전 확인 권장)

- 얼음 비율 약 10%: 물 비열 4.18 J/g·℃ × 8℃ ÷ 얼음 융해열 334 J/g ≈ 0.10 (얼음의 비열 차이는 무시한 근사)
- 결정이 생기면 나오는 열(잠열) 때문에 온도가 0℃로 올라간다는 점은 위 계산과 같은 원리
- 손난로: 아세트산나트륨 삼수화물 과냉각 용액, 녹는점 약 58℃, 굳을 때 약 54℃까지 올라간다는 것이 흔히 알려진 값
