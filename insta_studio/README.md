# Insta Studio

뉴스·커뮤니티 글의 **링크나 본문**을 넣으면 AI(Claude)가 **요약 · 이미지 제목 · 캡션 · 해시태그**를 만듭니다.
그 결과로 **3:4 인스타그램 이미지**(사진 + 하단 검은 그라데이션 + 가운데 흰 제목, 강조 키워드는 빨간 글씨)를 만들고,
휴대폰 공유하기나 Instagram API로 바로 올릴 수 있는 웹앱입니다. 휴대폰 브라우저에서 쓰도록 만들었습니다.

## 흐름

1. **소재 넣기** – 링크를 넣고 `가져오기`를 누르면 제목·본문·대표 이미지를 추출합니다. 추출이 막힌 사이트는 본문을 직접 붙여넣으면 됩니다.
2. **AI로 게시물 만들기** – 핵심 요약 3~5줄, 제목 후보 3개, 캡션, 해시태그, 게시 전 확인 사항을 만듭니다. 톤은 정보 전달 / 호기심 유발 / 공감·감동 중에서 고릅니다.
3. **이미지** – 제목 후보를 누르면 이미지에 바로 들어갑니다.
   - `*허미미*`처럼 별표로 감싼 글자는 빨간색(강조 색)으로 나옵니다.
   - 비율 3:4 / 4:5 / 1:1, 사진 배치(꽉 채우기 + 그라데이션 / 사진 위 + 검은 띠), 글씨 크기, 그라데이션 진하기, 정렬을 조절할 수 있습니다.
   - 배경은 원문 이미지 / 내 사진 업로드 / 단색 테마 중에서 고릅니다.
4. **올리기**
   - `공유하기`를 누르면 캡션이 복사되고, 휴대폰 공유 시트로 이미지가 Instagram 앱에 넘어갑니다.
   - `이미지 저장`과 `캡션 복사`를 따로 쓸 수도 있습니다.
   - `인스타그램에 바로 게시`는 Graph API 설정이 있을 때만 보입니다.

## 실행

```bash
cd insta_studio
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env   # 값 채우기
export $(grep -v '^#' .env | xargs)
uvicorn insta_studio.app:app --host 0.0.0.0 --port 8000
```

브라우저에서 `http://localhost:8000`을 엽니다. 같은 와이파이에 있는 휴대폰에서는 `http://<PC IP>:8000`으로 열면 됩니다.

| 환경 변수 | 설명 |
| --- | --- |
| `ANTHROPIC_API_KEY` | **필수.** Claude API 키 |
| `INSTA_STUDIO_MODEL` | 선택. 기본값 `claude-opus-5-5` |
| `APP_PASSWORD` | 선택. 인터넷에 공개 배포할 때 API 사용을 비밀번호로 막습니다 |
| `IG_USER_ID`, `IG_ACCESS_TOKEN` | 선택. Instagram 자동 게시용 (비즈니스/크리에이터 계정, 콘텐츠 게시 권한 토큰) |
| `PUBLIC_BASE_URL` | 자동 게시를 쓸 때 필수. Instagram이 이미지를 내려받을 이 서버의 공개 HTTPS 주소 |
| `IG_GRAPH_BASE` | 선택. 기본값 `https://graph.facebook.com/v21.0`. Instagram 로그인 토큰이면 `https://graph.instagram.com/v21.0` |

> Instagram API는 4:5보다 세로로 긴 이미지를 거부할 수 있습니다. 자동 게시가 실패하면 비율을 4:5로 바꾸세요. 휴대폰 공유로 올릴 때는 3:4 그대로 써도 됩니다.

## 주의

- **저작권:** 기사 사진과 본문의 저작권은 언론사와 작성자에게 있습니다. 원문 사진을 그대로 쓰거나 글을 베껴 올리면 신고를 받거나 계정이 정지될 수 있습니다. 직접 찍은 사진이나 무료 이미지를 쓰고, 출처를 꼭 표기하세요.
- **사실 확인:** AI는 원문에 있는 사실만 쓰도록 지시되어 있습니다. 그래도 게시 전에 이름, 숫자, 인용은 직접 확인하세요.
- **수집 보안:** 서버는 내부망 주소(SSRF) 요청을 막고, 받는 크기를 제한합니다.
